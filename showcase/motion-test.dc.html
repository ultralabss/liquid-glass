Anchored morph: automated enter / exit test

Each overlay is opened and closed programmatically. The harness listens for the ul:morph events every AnchoredMorph dispatches, samples the surface rect, the anchor hit-test and the stage opacity on every animation frame, and checks the result against the motion spec. Runs: clean enter, clean exit, reduced motion, and an interruption (close at 40 %, reopen at 60 %). The header overlays (megamenu, language popper, studio tooltip) run the same harness in landing/chrome/motion-test.
